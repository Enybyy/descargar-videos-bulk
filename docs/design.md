# Presentation direction

A batch video organizer for people building technical learning libraries. The first screen should let visitors classify sample metadata and inspect the resulting folder plan.

Colors: #F2F5F8 workspace, #FFFFFF sheet, #172A40 primary text, #536579 secondary text, #2457C5 actions, #19734D success. Typography: system UI for controls, monospace for paths. Layout: left-aligned source editor beside a wider output table, stacked on narrow screens.

```text
Bulk Video / source and documentation links
Title and explanation
[metadata editor + classify] [folder plan + filter + export]
                 classification rules and local execution
```

The distinctive element is the visible path from source metadata to a Civil 3D folder. No simulated download progress, fabricated transfer rates or claims that GitHub Pages downloads videos. Respect reduced motion; maintain visible keyboard focus and scroll tables within their own container.
